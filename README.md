# سلّم — تعلّم الإنجليزية من A1 إلى C2

موقع ثابت (static) لتعلّم اللغة الإنجليزية على ستة مستويات، تعمل من الملف مباشرة وعلى الهاتف دون الحاجة لخادم.

---

## ماذا يحتوي الموقع

- **6 مستويات** (A1 المبتدئ → C2 الاحتراف الكامل) × **3 وحدات** لكل مستوى = 18 وحدة.
- كل وحدة تحتوي على:
  - 8 كلمات مع معانيها ونطقها.
  - قاعدة نحوية مع أمثلة وتفسير بالعربية.
  - 5 تمارين تفاعلية (اختيار من متعدد، ملء فراغ، ترتيب كلمات، كتابة، تسجيل صوتي).
  - **مهمة إنتاج**: جملة مكتوبة أو ٣٠ ثانية تسجيل صوتي.
- **اختبار تحديد المستوى** (18 سؤال) يحدد مستواك الابتدائي.
- **بنك مفردات** إضافي: 108 كلمة (18 لكل مستوى)، قابلة للبحث، التصفية حسب المستوى، والإضافة للمراجعة.
- **مراجعة متباعدة (SRS)** حسب نظام سهولة المراجعة مع فترات متزايدة.
- **نقاط، سلسلة أيام متتالية، وشارات** (15 شارة).
- **تدريب النطق** (أصوات تصعب على الناطق بالعربية) مع NTT/TTS وتسجيل صوتي ومقارنة.
- **لوحة تقدم** مع خريطة حرارية للأسبوعين الماضيين.
- **دليل المنهج والمصادر** مع تمييز بين ما هو مؤكد وما هو تقديري.
- **إعدادات**: هدف يومي، وقت التذكير، الوضع الداكن/الفاتح.
- **PWA**: يمكن تثبيت الموقع كتطبيق على الهاتف ويعمل من دون إنترنت.

## ما هو مؤكد وما هو تقديري

**مؤكد:** CEFR، أوصاف القدرة (can-do)، الساعات الموجّهة، ربط الامتحانات، نظام المراجعة المتباعدة.

**تقديري:** عدد الكلمات (500–800 في A1… إلى 8,000–10,000+ في C2)، ترتيب الوحدات داخل المستويات، نتيجة اختبار التحديد، المدة المقترحة لكل جلسة.

## التشغيل

### الطريقة الأسهل (بدون خادم)
افتح ملف `index.html` مباشرة من المتصفح. كل شيء يعمل محلياً.

### باستخدام خادم محلي (مُستحسن للميزات المتقدمة)
```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory "path/to/sullam-english"
```
ثم افتح `http://127.0.0.1:8765/index.html`.

### التثبيت كتطبيق (PWA)
الموقع يتضمن ملف `manifest.webmanifest` و`sw.js` (service worker). المتصفح سيعرض إمكانية التثبيت كتطبيق على الهاتف أو سطح المكتب، وسيخزن الملفات محلياً للعمل دون إنترنت.

## بيانات المستخدم

تُحفظ جميع بيانات المستخدم (التقدم، النقاط، الكلمات، الإعدادات، الشارات) في `localStorage` تحت مفتاح `sullam.v1`. لا تُرسل أي بيانات لأي خادم خارجي.

## Grenzen النسخة الأولى (v1.0)

1. لا توجد مزامنة بين الأجهزة؛ البيانات محلية فقط.
2. التسجيل الصوتي يتطلب متصفحاً داعماً لـ `MediaRecorder` و الميكروفون.
3. NTT/TTS للنطق يعتمد على voices المتوفرة في المتصفح.
4. الربط الرسمي لـ IELTS يغطي B1–C1 فقط؛ المستويات الأخرى تحمل وسم "تقريبي".
5. لا يوجد خادم backend؛ كل المنطق في متصفحك.
